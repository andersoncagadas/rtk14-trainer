# RTK XIV Trainer

A single-player, offline trainer for **Romance of the Three Kingdoms XIV** (Steam, English).

Downloads are on the **[Releases](../../releases)** page:

- **RTK14-Trainer-exe.zip**: the single-file trainer (`RTK14 Trainer.exe`). Nothing to install.
- **RTK14-Trainer-portable.zip**: the same trainer with its own bundled Python.

From v1.04 on, the trainer checks this page for updates and can update itself
(sidebar **Update to vX** button, or **About → Check for updates**). Every download is checked
against its published SHA-256 before it replaces anything.

For single-player use only. Keep a backup save before big changes.
